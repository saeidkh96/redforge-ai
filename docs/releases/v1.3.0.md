# RedForge AI v1.3.0 — End-to-End Production Integration

v1.3.0 connects the production primitives introduced in v1.2.0 directly to the
ForgeRun lifecycle.

## Added

- ProductionRuntime integration in ForgeOrchestrator
- policy evidence persisted on ForgeRun
- deterministic risk scoring
- independent multi-agent run-gate consensus
- explicit human approve/reject API endpoints
- runtime evidence attached to each integrated run
- delivery-ready state after verification, consensus, and approval gates
- end-to-end integration validation helpers

## Run gate

A change can become delivery-ready only when the configured verification,
review, risk, and human-approval requirements are satisfied.

## Boundary

Application-level runtime controls are not a kernel-level sandbox. Fully
untrusted execution still requires a container, VM, or equivalent isolation.
