# RedForge AI v1.5.0

## Autonomous Runtime Integration

RedForge AI v1.5.0 is the first integration milestone after the v1.4.0 autonomous-engineering capability foundation.

This release connects the existing ForgeRun workflow with the newer graph, checkpointing, repository intelligence, engineering memory, Docker execution, evaluation, and release-control capabilities.

## Highlights

- Integrated autonomous engineering runtime
- ForgeGraph and checkpoint integration
- Repository-aware impact analysis
- Specialized engineering agent roles
- Engineering memory integration
- GitHub issue intake foundations
- Docker-based isolated execution
- Benchmark and reliability evaluation foundations
- Workspace boundary enforcement
- Secret redaction
- Fail-closed release gating
- Updated autonomy API
- Runtime and configuration integration

## Workflow

Issue ? Repository Understanding ? Plan ? Code ? Patch ? Test ? Repair ? Verify ? Policy ? Risk ? Review ? Human Approval ? Audit ? Delivery

## Engineering Principle

> Generation proposes. Verification decides.

Generation remains separated from verification, policy enforcement, risk evaluation, approval, and delivery.

## Validation

The v1.5.0 release must pass:

- Ruff
- MyPy
- pytest
- v1.5.0 validation
- Git whitespace validation

Some foundations for later roadmap milestones are already present in the codebase. Their presence does not make them separate released versions. Future releases will focus on deeper integration, real-world automation, evaluation, reliability, and production hardening.
