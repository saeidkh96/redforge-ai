# RedForge AI v1.6.0 — Autonomous Engineering Completion Release

v1.6.0 consolidates the remaining planned RedForge engineering capabilities into the active
runtime while keeping generation subordinate to deterministic verification and human control.

## Implemented

- signed GitHub issue webhook intake with replay protection and label gating
- authenticated issue retrieval and issue-to-run execution
- controlled branch/commit/push/pull-request delivery
- deeper multi-language dependency analysis
- Python symbol and call-graph evidence
- changed/impacted symbol tracking and targeted test suggestions
- specialized planner/coder/repair/reviewer/verifier roles
- persistent engineering memory and prior-run recall in the autonomous runtime
- benchmark observations and reliability metrics including TP/TN/FP/FN, precision, recall,
  accuracy, F1, and history persistence
- secret redaction, workspace boundaries, evidence integrity hashes, and fail-closed release gates
- Docker execution evidence, checkpoint/resume, policy, risk, deterministic review, human approval,
  tamper-evident audit, and GitHub delivery through the existing production pipeline

## Release boundary

The package and API version for this implementation is **1.6.0**.

> Generation proposes. Verification decides.
