# RedForge AI v1.6.1 — Maintenance Hardening

v1.6.1 is a maintenance and security-hardening patch on top of v1.6.0. It does not introduce a new product roadmap.

## Changes

- Fail-closed `/api/v1/autonomy/github-issue/run` when live GitHub automation is disabled.
- Server-managed GitHub credentials and workspace for live issue runs; request bodies no longer carry GitHub tokens or arbitrary workspace roots.
- Automatic publication requires the separate `REDFORGE_GITHUB_AUTO_PUBLISH_ENABLED` gate.
- Retry-safe webhook delivery states: `processing`, `completed`, and `failed`.
- Failed webhook deliveries can be retried while completed/in-flight deliveries remain idempotent.
- Invalid webhook payloads return a controlled client error.
- Duplicate GitHub live-automation configuration removed from `.env.example`.
- Obsolete staged v1.5→v2.0 roadmap document removed; v1.6 remains the completed autonomous-engineering milestone.

## Release policy

Live GitHub automation remains opt-in. Credentials are loaded from server configuration, network egress and repository permissions must be explicitly configured, and RedForge release gates remain authoritative.
