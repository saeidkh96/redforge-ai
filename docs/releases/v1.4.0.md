# RedForge AI v1.4.0 — Autonomous Engineering Roadmap Consolidation

v1.4.0 consolidates the capability scope that was planned from v1.4.0 through v2.0.0 into one release target.

## Added
- Real agent/state-graph orchestration with conditional edges and checkpoint/resume.
- Docker-based isolated execution with CPU, memory, timeout, network and read-only-root controls.
- Python import/dependency impact analysis with direct/transitive blast radius.
- Provider-independent LLM routing with fallback, failure budgets and usage evidence.
- SQLite-backed engineering memory for failures, repairs and repository lessons.
- GitHub issue autonomy envelope with deterministic branch/workspace planning.
- Autonomous platform facade that composes existing RedForge v1.3 stages.

## Boundary
This is a consolidated capability layer. It does not claim perfect hostile-code isolation,
universal repository support, or production-tested GitHub credentials on every host.

Generation proposes. Verification decides.
